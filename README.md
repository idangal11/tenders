# רדאר מכרזים

מערכת שסורקת כל בוקר מכרזים, קולות קוראים ומאגרי ספקים בישראל בתחומי הטמעת AI, פיתוח, ניתוח נתונים, הרצאות וסדנאות, ומדרגת כל אחד לפי ההתאמה לעסק חדש וקטן.

**האתר:** פרוס ב-Vercel (כל push ל-`main` מעלה גרסה חדשה)

## איך זה עובד
1. **כל יום ב-7:40 שעון ישראל** רצה משימה מתוזמנת של Claude. היא פועלת לפי [SCANNER.md](SCANNER.md): סורקת את מנהל הרכש, משרד החינוך וגפן, רשויות מקומיות, גופים ציבוריים, המטה הלאומי ל-AI ורשות החדשנות.
2. הסורק מעדכן את `site/data/tenders.json` ואת `site/data/meta.json` (התדריך היומי), ועושה commit ו-push לענף `main`.
3. כל push ל-`main` גורם ל-Vercel לפרסם מחדש את התיקייה `site/` (ההגדרות ב-`vercel.json`). הבנייה בודקת שקבצי הנתונים תקינים, וקובץ נתונים שבור לא יעלה לאוויר.

## מבנה
- `site/index.html`: האתר (עמוד אחד, בלי build). הסימונים "מעניין / מגיש / לא רלוונטי" נשמרים בדפדפן.
- `site/data/tenders.json`: כל המכרזים, כולל סגורים (לא נמחקים).
- `site/data/meta.json`: זמן הסריקה האחרונה, התדריך והמקורות.
- `site/data/scans/`: היסטוריה של תדריכים יומיים.
- `SCANNER.md`: ההוראות לסורק. עריכה שלו משנה את הסריקה מהבוקר הבא.

## הרצה מקומית
```
cd site && python3 -m http.server 8000
```
ופתיחת http://localhost:8000
